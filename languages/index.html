Languages

Thirty languages, one engine

Release {{ site.data.release.tag }}. Servirtium ships native libraries for Linux (glibc and musl), macOS, Windows and FreeBSD, and four packaged artifacts: the Java jar, the .NET nupkg, the npm tarball and the Swift artifact bundle. Nothing is on a language registry. Every other language vendors the binding's source at the release tag and loads the native library from the release. Each page below has the exact steps, copyable record and playback snippets, and a prompt to hand to a coding agent.
