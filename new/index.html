Adding a Servirtium language

Servirtium is now one native engine + thin per-language bindings, all in a single monorepo. You don't hand-build a recorder/replayer/server from scratch anymore — you write a thin FFI binding over the shared engine, and the existing bindings are your template.

To add a language: open servirtium/servirtium-vcr in a coding agent and ask it (e.g. "make a Perl binding"). It has the engine's C ABI and a bindings table covering every FFI mechanism (ctypes, cgo, FFM, P/Invoke, koffi, C NIF, …) — pick the nearest existing binding and copy its shape. See LLM.md in that repo for the orientation map.
